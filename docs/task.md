# Задание 3 — Мини-продукт с LLM-аналитикой (5 баллов)

**Цель**: собрать работающий продукт, который решает аналитическую задачу с помощью **<u>ИИ-агента</u>**.

## Что нужно сделать

Реализовать один из форматов на выбор:

- Telegram-бот: пользователь отправляет датасет (CSV/Excel), бот возвращает результат анализа данных, ключевые метрики и/или графики, инсайды.
- Веб-интерфейс: страница (Streamlit, Flask, FastAPI, Next.js и т.п.), куда загружается файл и на его основе выводится результат анализа данных, ключевые метрики и/или графики, инсайды.
- Любой другой формат, решающий реальную задачу анализа данных, — по согласованию с преподавателем.

**Важно**: приложение должно использовать LLM через API программно, а не через ручной веб-интерфейс ChatGPT/Claude. LLM должна сама проводить анализ данных путем вызова интерпретатора кода (tool или MCP-сервер это должен быть), а не генерировать текст на основе подставленных в промпт характеристик датасета.  

**Подсказка**: для реализации агентной среды можно использовать соответствующие фреймоврки.

## Формат сдачи

- Ссылка на работающее приложение (Telegram-бот, сайт — что угодно, к чему можно зайти/написать и проверить) или скрины работы приложения в отчете.
- GitHub/Gitlab-репозиторий с кодом и README.
